# 🌱 EVA IONI 2.0 (Python Edition)

Robot open-source per orti urbani con AI, sensori ambientali, irrigazione autonoma e biodiversità.

## 🚀 Features

### 🌍 Environmental Sensors
- Air Quality (PM2.5, PM10, CO2, VOC)
- Weather Station (temp, humidity, wind, rain, UV)
- Acoustic Sensors (bird songs, noise pollution)
- Light Sensors (PAR, lux)

### 💧 Autonomous Irrigation
- Smart scheduling based on soil moisture
- Drip irrigation control
- Weather-aware operation

### 🗺️ Biodiversity Mapping
- AI-powered species detection
- Pollinator tracking
- Invasive species alert
- Citizen science integration

### 🧠 AI Recommendations
- Personalized gardening advice
- Pest prediction and prevention
- Crop rotation suggestions

### 🔌 Rich APIs
- REST API (FastAPI)
- WebSocket for real-time data
- Developer documentation
