# Bounties — MyZubster Marketplace

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Marketplace bounties may cover garden/sensor APIs, marketplace services, UI/API integration, validation, testing, accessibility, documentation and security hardening.

## Evidence

The issue must define the deliverable and acceptance criteria. Use tests, screenshots, API examples or other reproducible evidence appropriate to the task.

## Reward truth

Historical XMR/MYZ bounty amounts are project records, not proof of settlement. MYZ in the current core platform is an internal reward/accounting ledger. External payment is `PAID` only after the applicable independent verification.

## Safety

Do not expose user secrets or precise sensitive locations. Sensor/physical-world work must not require unauthorized access or unsafe intervention.

## Issues

Use this repository's GitHub issues and link the implementation PR to the selected bounty.
