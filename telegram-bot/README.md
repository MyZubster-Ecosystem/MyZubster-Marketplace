# 🤖 AgricoloBot Telegram Bot

Bot Telegram per controllare AgricoloBot da remoto.

## Installazione

1. Crea un bot su Telegram con @BotFather
2. Copia il token
3. Clona il repository
4. Installa le dipendenze:

```bash
npm install
```

5. Configura il token:

```bash
cp .env.example .env
nano .env
```

6. Avvia il bot:

```bash
npm start
```

## Comandi

- /start - Benvenuto
- /help - Lista comandi
- /status - Stato robot
- /water - Irrigazione
- /plant - Semina
- /analyze - Analisi suolo
- /sensors - Dati sensori
