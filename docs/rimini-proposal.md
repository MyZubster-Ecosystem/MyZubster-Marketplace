# MyZubster per gli Orti Urbani di Rimini

## Proposta di Collaborazione

### Chi Siamo
MyZubster è una piattaforma open-source per lo scambio di servizi con pagamenti in Monero (XMR), con focus su orti urbani e permacultura.

### Cosa Proponiamo
1. **Mappatura interattiva** degli orti urbani di Rimini
2. **Monitoraggio IoT** con sensori Arduino (pH, EC, temperatura)
3. **Robot software AgricoloBot** per automazione
4. **Pagamenti privati** in Monero per servizi

### Perché Rimini
- Il Comune ha un Piano del Verde attivo
- Daniel Ioni è un developer di Rimini
- Hera sta investendo in economia circolare

### Prossimi Passi
