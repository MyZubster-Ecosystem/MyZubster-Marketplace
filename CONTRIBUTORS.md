# MyZubster Marketplace Contributors

This file serves as a voluntary registry of **MyZubster Digital Identities** for contributors to this repository.

> **Note:** This is for contribution provenance and collaboration. It is **not KYC, SPID/CIE, a government identity, or a qualified electronic signature**. Never publish private keys, seed phrases, credentials, private addresses or unnecessary personal data. A public alias is enough.

---

## How to Add Your Identity

1. Fork this repository
2. Add your identity entry below following the format
3. Submit a pull request

## Identity Format

```text
IDENTITY
GitHub alias: @your-handle
Public display name/alias: <optional>
Main contributions: <issue/PR links>
Public profile links: <optional>
```
